# Skill Quest ✦

**Learn, Create, Grow** — a lightweight browser arcade game where you collect knowledge-themed items, build combos, and dodge bombs before time runs out.

## Play locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Select **Start Quest** and begin collecting XP.

## How to play

- Collect stars, gems, books, and lightbulbs for XP.
- Consecutive collectibles build a combo and increase points.
- Avoid bombs: they deduct points and reset your combo.
- Score enough XP to progress from Rookie to Learner, Explorer, Master, and Legend.
- Use touch or mouse. Keyboard shortcuts include **P** or **Esc** to pause/resume.

## Publish with GitHub Pages

1. Open this repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment to finish. The site URL will be shown in the Pages settings.

## Technology

Plain HTML, CSS, and JavaScript. No frameworks, package installation, or API keys required.
